# ✅ **60-Day DSA Roadmap (1 Hour/Day)**

**Covers:** 

→Arrays 
→ Hashmaps 
→ Sliding Window 
→ Two Pointers 
→ Binary Search 
→ Recursion 
→ Backtracking 
→ Linked List 
→ Trees 
→ Graphs 
→ Heaps 
→ DP 
→ Stack & Queue







Each day ~1 hour:
**20 mins learning + 40 mins problems (2–4 per day).**







# 🌟 **Phase 1: Foundations (Days 1–12)**

### **📌 Arrays & Strings (Days 1–6)**

Learn: traversal, prefix sum, kadane, left/right operations
Problems:

* Reverse array
* Move zeros
* Kadane max subarray
* Rotate array
* String reverse
* Palindrome








### **📌 Hashmaps & Sets (Days 7–9)**

Learn: frequency maps, unique sets, anagram logic
Problems:

* Two sum
* First non-repeating char
* Count frequency
* Check duplicates







### **📌 Sliding Window (Days 10–12)**

Learn: fixed window, variable window
Problems:

* Max sum window
* Longest substring without repeat
* Count anagrams
* Fruits into basket






# 🌟 **Phase 2: Core Patterns (Days 13–26)**

### **📌 Two Pointers (Days 13–15)**

Problems:

* Pair sum
* 3-sum
* Sort colors
* Remove duplicates

---

### **📌 Binary Search (Days 16–19)**

Problems:

* Search position
* First/last occurrence
* Square root
* Peak element
* Search in rotated array

---

### **📌 Recursion & Backtracking (Days 20–26)**

Learn: recursion tree, base condition
Problems:

* Factorial, Fibonacci
* Subsets
* Permutations
* N-Queens
* Sudoku solver

---

# 🌟 **Phase 3: Linked Structures (Days 27–36)**

### **📌 Linked List (Days 27–31)**

Problems:

* Reverse list
* Cycle detect
* Middle element
* Merge two lists
* Remove Nth node

---

### **📌 Stack & Queue (Days 32–36)**

Problems:

* Valid parentheses
* Min stack
* Implement queue using stacks
* Next greater element

---

# 🌟 **Phase 4: Trees & Graphs (Days 37–50)**

### **📌 Trees (BT + BST) (Days 37–43)**

Learn: Inorder, Preorder, Postorder
Problems:

* Height of tree
* Leaf count
* Lowest common ancestor
* Validate BST

---

### **📌 Graphs (BFS + DFS + Shortest Path) (Days 44–50)**

Problems:

* BFS traversal
* DFS traversal
* Number of islands
* Cycle detection
* Dijkstra algorithm
* Graph shortest path

---

# 🌟 **Phase 5: Advanced (Days 51–60)**

### **📌 Heaps + Priority Queue (Days 51–55)**

Problems:

* K largest elements
* Kth smallest
* Merge K sorted lists
* Heap sort

---

### **📌 Dynamic Programming (Days 56–60)**

Beginner DP set:

* Climbing stairs
* House robber
* Coin change
* LCS
* 0/1 knapsack basic

---

# 🎯 Final Output:

By Day 60, you will be able to solve:
✔ 200+ interview-quality problems
✔ All major patterns (sliding window, two pointers, recursion, BFS/DFS, DP)
✔ You can handle LeetCode medium-level questions
✔ Ready for product company interviews
