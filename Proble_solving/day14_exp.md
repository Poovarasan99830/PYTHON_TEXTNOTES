# rotated sorted array

rotated sorted array means a sorted array shifted or rotated from some pivot point while maintaining sorted order in parts of the array.

Real World Analogy:
   Clock think pannunga.
       10 11 12 1 2 3
   Circular-ah rotate aagite irukum.
       Same concept.
