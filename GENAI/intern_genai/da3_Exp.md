
# Model
   A Model is:👉 A trained AI program that learns patterns from data and makes predictions.

# Workflow          
Data → Train Model → Learned Model → Prediction
             
# Example in Code
model = LinearRegression() --->Creates empty ML model
model.fit(x,y)             --->Model learns patterns from data.
model.predict([[6]])       --->Model predicts output for new input.
