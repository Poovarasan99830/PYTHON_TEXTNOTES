# 📌 Generative AI Applications

## 1. Chatbots & AI Assistants

AI-based systems that talk with users like humans.

### Examples:

* OpenAI's ChatGPT
* Google Gemini
* Virtual customer support bots

### Uses:

* Answer customer questions
* 24/7 support
* Booking, enquiry handling
* Personal assistants

### Real-Time Example:

Swiggy support bot, bank chatbot, hospital enquiry bot

## 2. Code Generation

AI can automatically write code from text instructions.

### Examples:

* GitHub Copilot
* ChatGPT
* Amazon CodeWhisperer

### Uses:

* Generate Python code
* Debug errors
* Create websites/apps
* SQL query generation

### Example:

You type:

> “Create login page using Flask”

AI generates the code automatically.
