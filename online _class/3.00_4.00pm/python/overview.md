# Daily Class Structure (2 Hours)

### **Theory (60 Minutes)**

* Explain concepts
* Real-world examples
* Live coding demonstration

### **Hands-on Coding (45 Minutes)**

* Write programs together
* Solve coding exercises
* Debugging session

### **Q&A & Task Explanation (15 Minutes)**

* Clarify doubts
* Explain the next practice task

---

# Gap Day (Practice Day) Structure (Self-Practice)

* ✅ Revise the previous class (15 minutes)
* ✅ Complete 10–15 coding programs (60–90 minutes)
* ✅ Solve 5 debugging questions (20 minutes)
* ✅ Complete 1 mini task (30–45 minutes)
* ✅ Submit code through GitHub or Google Classroom

---

# Internship Deliverables

* **12 Instructor-led Classes**
* **12 Practice Sessions**
* **100+ Python Practice Programs**
* **3 Weekly Assignments**
* **1 Mini Project**
* **1 Final Assessment**
* **Internship Completion Certificate**

This alternate-day plan gives students enough time to **learn on class days** and **practice independently on the gap days**, which improves coding confidence and problem-solving skills.
